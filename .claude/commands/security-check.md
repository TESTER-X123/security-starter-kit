이 프로젝트(또는 지정된 파일: $ARGUMENTS)의 HTML/CSS/JS 코드를 점검해서,
클라이언트 사이드에서 흔히 발생하는 보안 이슈가 있는지 확인해줘.

## 점검 항목

1. **XSS 가능성**
   - `innerHTML`, `outerHTML`에 사용자 입력이나 외부 데이터가 이스케이프 없이 들어가는 부분
   - 템플릿 문자열로 HTML을 조립할 때 값 검증/이스케이프가 빠진 부분

2. **민감 정보 노출**
   - 소스 코드에 하드코딩된 API 키, 토큰, 비밀번호가 있는지
   - `console.log`에 민감한 값이 그대로 찍히고 있는지

3. **안전하지 않은 외부 리소스**
   - `http://`로 시작하는 외부 스크립트/스타일 로드 (mixed content 위험)
   - `target="_blank"`인 링크에 `rel="noopener noreferrer"`가 빠져있는지

4. **입력 검증**
   - 폼 입력값을 서버로 보내기 전 클라이언트 측 검증이 있는지 (참고용, 서버 검증이 항상 우선)

## 출력 형식

발견된 이슈를 다음 순서로 정리해줘:
- 파일/줄 위치
- 이슈 설명
- 위험도 (critical/high/medium/low)
- 수정 제안 코드

이슈가 없으면 "점검한 범위에서는 특별한 이슈를 찾지 못했습니다"라고 명확히 말해줘.
추측이나 과장된 위험도 표현은 하지 말고, 근거를 함께 제시해줘.
