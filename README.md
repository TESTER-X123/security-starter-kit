# Security Starter Kit

바닐라 HTML/CSS/JS로 새 진단 도구·리포트 페이지를 빠르게 시작하기 위한 스타터킷입니다.
프레임워크나 빌드 도구 없이, `index.html`만 열어도 바로 동작합니다.

## 포함된 것

- **디자인 시스템** (`css/styles.css`): 다크/퍼플 톤 CSS 변수, 버튼, 카드, 배지, 상태 표시 컴포넌트
- **취약점 심각도 배지**: Critical / High / Medium / Low
- **상태 배지**: SECURE / VULNERABLE
- **진단 리포트 카드 템플릿**: ID, 제목, 설명, 영향 범위/권고 조치, 상세 보기 토글
- **기본 JS 패턴** (`js/app.js`): 상세 보기 토글 같은 자주 쓰는 인터랙션 예시

## 사용 방법

1. 이 저장소를 클론하거나 다운로드
2. `index.html`을 브라우저로 열기 (또는 VS Code Live Server 사용)
3. 새 프로젝트를 시작할 땐 `index.html`의 컴포넌트를 참고해서 필요한 부분만 복사해 쓰기
4. 배지 색상 등은 `css/styles.css` 상단의 CSS 변수(`:root`)만 바꾸면 전체 톤이 바뀝니다

## 커스터마이징

```css
:root {
  --accent: #a855f7;   /* 포인트 컬러 */
  --bg: #0d0b1a;        /* 배경색 */
}
```

## 폴더 구조

```
starter-kit/
├── index.html          # 컴포넌트 쇼케이스 + 리포트 카드 예시
├── css/
│   └── styles.css       # 디자인 시스템 (버튼/카드/배지/상태)
├── js/
│   └── app.js            # 재사용 가능한 인터랙션 패턴
├── CLAUDE.md              # 프로젝트 메모리 (코딩 컨벤션, 보안 규칙)
└── .claude/
    └── settings.json      # 프로젝트 권한 설정 (민감 파일 접근 차단 등)
```

## 왜 만들었나요

취약점 진단 리포트나 간단한 내부 도구 페이지를 만들 때마다 카드/배지/버튼 스타일을
매번 새로 짜는 게 비효율적이라, 3번 이상 반복해서 썼던 패턴만 모아뒀습니다.
